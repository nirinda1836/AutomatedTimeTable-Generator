# 📅 Automated Time Table Generator

An automated timetable generation system designed to simplify academic scheduling and reduce the manual effort involved in creating class timetables.

## 📌 Project Overview

The **Automated Time Table Generator** is a Python-based application that helps generate academic timetables by organizing subjects, faculty, classrooms, and available time slots.

The system aims to minimize scheduling conflicts, improve resource utilization, and make timetable creation more efficient.

## 🎯 Objectives

- Automate the academic timetable generation process.
- Reduce manual scheduling efforts.
- Avoid faculty and classroom scheduling conflicts.
- Organize subjects and time slots efficiently.
- Improve timetable management and accuracy.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/nirinda1836/Automated-Time-Table-Generator.git
```

### 2. Navigate to the Project Folder

```bash
cd Automated-Time-Table-Generator
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Project

```bash
python main.py
```

## 🔄 How It Works

1. Collects academic scheduling information.
2. Identifies subjects, faculty, classrooms, and available time slots.
3. Applies scheduling rules and constraints.
4. Allocates subjects to appropriate time slots.
5. Checks for scheduling conflicts.
6. Generates the final academic timetable.
